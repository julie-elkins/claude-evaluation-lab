# Slide and recording assets

The course deck will use the cream visual direction from the Claude Architect
Lab, adapted for Julie's YouTube channel.

The repository visual rules are documented in
[`course/VISUAL-SYSTEM.md`](../course/VISUAL-SYSTEM.md). Use the same palette
in the PowerPoint deck: cream background, navy text, blue workflow/input,
orange evaluation/evidence, sage pass/recovery, and red failure/block.

Each lesson slide sequence will include:

- a concept anchor;
- a workflow or evidence diagram;
- a technical visual or screen-demo placeholder; and
- speaker notes containing the recording script and expected result.

The production-oriented track adds trace diagrams, operational signal cards,
privacy-boundary callouts, incident records, trace-to-test-case flows, threat
models, authority-boundary cards, telemetry-health states, and local
instrumentation-to-alert workflows. The live Claude adapter remains optional so
the required recording path does not depend on credentials, provider
availability, or changing API syntax.

The editable PowerPoint deck will be added after the lesson scripts and lab
contracts are stable. This prevents the visual deck from teaching a workflow
that later changes underneath it.
