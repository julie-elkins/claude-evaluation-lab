# Slide and recording assets

The course deck will use the cream visual direction from the Claude Architect
Lab, adapted for Julie's YouTube channel.

Each lesson slide sequence will include:

- a concept anchor;
- a workflow or evidence diagram;
- a technical visual or screen-demo placeholder; and
- speaker notes containing the recording script and expected result.

The editable PowerPoint deck will be added after the lesson scripts and lab
contracts are stable. This prevents the visual deck from teaching a workflow
that later changes underneath it.
